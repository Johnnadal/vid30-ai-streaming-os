# Vid30 Video Files

This directory contains the video files served by the web MVP. Each founder film (Vid30 Original) maps to an MP4 file in this directory.

## File Naming Convention

Files follow the pattern: `vid30-{film-id}.mp4`

Example:
- `vid30-echoes-of-creation.mp4` → Echoes of Creation
- `vid30-neon-consciousness.mp4` → Neon Consciousness

## Adding Videos

1. Place your MP4 file in this directory with the correct name
2. Ensure it's a valid MP4 file that plays in HTML5 `<video>` element
3. No additional configuration needed — it's automatically served by Vite

## Placeholder Files

Placeholder `.mp4` files are included for development. Replace them with actual video content before deployment.
